# Vue Interactive Applications

A collection of interactive web applications built with Vue 3 to demonstrate foundational front-end development concepts including reactive data binding, event handling, computed properties, user input, and dynamic interface updates.

## Applications

### Book App
An interactive application that allows users to enter book information and dynamically update the displayed title, author, and subject.

### Distance Converter
A reactive distance conversion tool that allows users to convert values between centimeters, meters, kilometers, inches, feet, and miles.

## Technologies Used

- Vue 3
- JavaScript
- HTML5
- CSS3

## Skills Demonstrated

- Vue `v-model` data binding
- Event handling with Vue
- Vue methods and computed properties
- User input validation
- Dynamic UI updates
- JavaScript conversion logic
- HTML/CSS interface design

## Project Background

Originally developed as part of university coursework in web development and maintained here as a demonstration of introductory Vue.js application development.
